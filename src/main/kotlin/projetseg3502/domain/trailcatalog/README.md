# Catalogue des sentiers — Support

Expose les informations sur les sentiers de la CCN (nom, type, surface, difficulté, saison
d'ouverture, secteur, zone, stationnement, tracé) à partir de la source publiée par la CCN.
Le club ne tient pas lui-même les informations sur les sentiers ; ce sous-domaine agit comme
un adaptateur de lecture seule sur les données externes.

Entités : `Trail` (vue sur les données CCN).
